## Интерпретация результатов

### Отношение DLC/игра
Показывает среднее количество DLC на одну игру для данного издателя.
- Высокое значение (>5) означает, что издатель активно выпускает DLC
- Низкое значение (<1) означает, что издатель редко выпускает DLC

### Среднее отношение positive/negative
Показывает математическое ожидание отношения положительных отзывов к отрицательным.
- Значение >10 - очень положительные отзывы
- Значение 5-10 - хорошие отзывы
- Значение 1-5 - смешанные отзывы
- Значение <1 - больше отрицательных отзывов

## Примечания

1. **Пересечение групп**: Одна игра может поддерживать несколько платформ (например, Windows, Mac и Linux одновременно), поэтому она будет учтена в статистике для каждой из этих платформ.

2. **Топ-5 издателей**: В каждом ценовом интервале для каждой платформы выбираются только топ-5 издателей по отношению DLC/игра.

3. **Пустые интервалы**: Если для какого-то ценового интервала нет игр, он не будет показан в результатах.

4. **Издатели без игр с отзывами**: Если у издателя нет игр с отзывами, среднее отношение будет 0.00.

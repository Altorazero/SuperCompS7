# Пример CSV вывода

Это пример того, как будет выглядеть файл `analysis_results.csv` после выполнения программы.

## Формат файла

CSV файл содержит следующие столбцы:
1. **Платформа** - Windows, Mac или Linux
2. **Цена_мин** - Начало ценового интервала ($)
3. **Цена_макс** - Конец ценового интервала ($)
4. **Издатель** - Название издателя
5. **Количество_игр** - Число опубликованных игр
6. **DLC_на_игру** - Среднее отношение DLC к количеству игр
7. **Отношение_отзывов** - Среднее отношение положительных отзывов к отрицательным

## Использование

### Импорт в Excel
1. Откройте Excel
2. Выберите "Файл" → "Открыть"
3. Выберите `analysis_results.csv`
4. Excel автоматически распознает разделители

### Импорт в Google Sheets
1. Откройте Google Sheets
2. Выберите "Файл" → "Импорт"
3. Загрузите `analysis_results.csv`
4. Выберите разделитель: запятая

### Обработка в Python
```python
import pandas as pd

# Чтение CSV файла
df = pd.read_csv('analysis_results.csv')

# Анализ данных
print(df.head())
print(df.describe())

# Фильтрация
windows_games = df[df['Платформа'] == 'Windows']
```

## Примечания

1. **Кодировка**: Файл сохраняется в UTF-8 для корректного отображения русских символов
2. **Разделитель**: Используется запятая (`,`)
3. **Кавычки**: Имена издателей заключены в кавычки для обработки запятых в названиях
4. **Числа**: Используется точка (`.`) как десятичный разделитель
5. **Точность**: Числовые значения округлены до 2 знаков после запятой

# Анализ данных Steam Games с использованием OpenMPI

## Описание задачи

Программа выполняет параллельный анализ большого CSV файла с данными об играх Steam, используя OpenMPI для распределения вычислений на кластере из 4 узлов (2 CPU + 2 GPU).

### Задание

1. Группировка данных по поддерживаемой платформе (Windows, Mac, Linux) - группы могут пересекаться
2. Внутри каждой платформы группировка по цене с интервалом $5
3. В каждой ценовой группе находим 5 издателей с наибольшим числом дополнений (dlc_count) по отношению к числу изданных игр
4. Для каждого издателя выводим:
   - Число опубликованных игр
   - Математическое ожидание отношения числа положительных отзывов к отрицательным

## Формат входных данных

Программа ожидает CSV файл `games.csv` со следующими полями (индексы указаны):

- [0] AppID
- [1] Name
- [6] Price
- [8] DLC count
- [17] Windows (True/False)
- [18] Mac (True/False)
- [19] Linux (True/False)
- [23] Positive reviews
- [24] Negative reviews
- [33] Publishers

Пример данных:
```csv
AppID,Name,Release date,Estimated owners,Peak CCU,Required age,Price,Discount,DLC count,About the game,Supported languages,Full audio languages,Reviews,Header image,Website,Support url,Support email,Windows,Mac,Linux,Metacritic score,Metacritic url,User score,Positive,Negative,Score rank,Achievements,Recommendations,Notes,Average playtime forever,Average playtime two weeks,Median playtime forever,Median playtime two weeks,Developers,Publishers,Categories,Genres,Tags,Screenshots,Movies
```

## Требования

- Debian-based Linux система
- OpenMPI установлен и настроен
- SLURM для управления заданиями
- Компилятор C++ с поддержкой C++11 или выше
- Доступ к 4 узлам кластера: altocpu1, altocpu2, altogpu1, altogpu2

## Установка и компиляция

### 1. Компиляция программы

```bash
make
```

Эта команда скомпилирует `steam_analysis.cpp` и создаст исполняемый файл `steam_analysis`.

### 2. Копирование на общую файловую систему

```bash
make install
```

Эта команда скопирует исполняемый файл в `/mnt/share/`, где он будет доступен всем узлам кластера.

### 3. Подготовка данных

Убедитесь, что файл `games.csv` находится в `/mnt/share/`:

```bash
cp games.csv /mnt/share/
```

## Запуск

### Запуск через SLURM

```bash
sbatch steam_analysis.slurm
```

### Проверка статуса задания

```bash
squeue -u $USER
```

### Просмотр результатов

После завершения задания результаты будут в следующих файлах:

- `steam_analysis.out` - стандартный вывод программы
- `steam_analysis.err` - сообщения об ошибках (если есть)
- `analysis_results.txt` - основной файл с результатами анализа

```bash
cat steam_analysis.out
cat analysis_results.txt
```

### Ручной запуск для тестирования

Для локального тестирования можно запустить программу напрямую:

```bash
mpirun -np 8 ./steam_analysis games.csv
```

## Конфигурация SLURM

Файл `steam_analysis.slurm` настроен следующим образом:

- **Партиция**: debug
- **Узлы**: altocpu1, altocpu2, altogpu1, altogpu2
- **Задач на узел**: 2
- **Всего процессов**: 8 (2 задачи × 4 узла)

## Алгоритм работы

1. **Инициализация MPI**: Программа инициализирует MPI и определяет количество процессов и ранг текущего процесса
2. **Распределение данных**: Файл CSV читается всеми процессами, но каждый процесс обрабатывает только свою часть строк (распределение round-robin)
3. **Параллельная обработка**: Каждый процесс:
   - Читает свои строки из CSV
   - Фильтрует игры по платформам
   - Группирует по ценовым интервалам
   - Вычисляет статистику для издателей
4. **Агрегация результатов**: Главный процесс (rank 0) собирает данные и записывает результаты в файл
5. **Синхронизация**: MPI барьеры обеспечивают корректную последовательность обработки платформ

## Особенности реализации

### Использование GPU узлов

Хотя задача в основном связана с обработкой данных CPU, программа запускается на всех 4 узлах, включая GPU узлы, что соответствует условию задания.

### Парсинг CSV

Программа корректно обрабатывает:
- Поля в кавычках
- Запятые внутри полей
- Пустые значения

### Обработка ошибок

Программа безопасно обрабатывает:
- Отсутствующие или некорректные числовые значения
- Пустые поля издателей
- Деление на ноль при расчете отношений

При использовании 8 процессов (2 на узел × 4 узла) программа эффективно распределяет нагрузку:
- Каждый процесс обрабатывает 1/8 часть данных

- Время выполнения пропорционально размеру данных

## Решение проблем

### Ошибка компиляции "mpic++ not found"

Убедитесь, что OpenMPI установлен:
```bash
sudo apt-get install libopenmpi-dev openmpi-bin
```

### Ошибка "cannot open file games.csv"

Проверьте, что файл находится в правильной директории:
```bash
ls -l /mnt/share/games.csv
```

### SLURM задание не запускается

Проверьте доступность узлов:
```bash
sinfo
```

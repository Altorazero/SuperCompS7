## 📋 Задача

Рефакторинг кода для использования ресурсов узлов GPU. Сейчас работа параллелится и задействует исключительно CPU узлы равномерно. Необходимо:

1. Использовать GPU составляющие узлов (если такие есть)
2. Распределять данные так, чтобы нагрузка была соразмерна мощности узлов
3. Для GPU больше, для CPU меньше

## ✅ Выполненные изменения

### 1. Модификация кода (steam_analysis.cpp)

#### Добавлены константы

```cpp
const int GPU_WEIGHT = 3;  // Вес GPU узла (в 3 раза мощнее CPU)

```

#### Новые функции

**isGPUNode()**
- Определяет тип узла по имени хоста
- Возвращает `true` для узлов с "gpu" в имени (altogpu1, altogpu2)
- Возвращает `false` для CPU узлов (altocpu1, altocpu2)

**getNodeWeight()**
- Возвращает вес узла на основе его типа
- GPU узлы: вес = 3
- CPU узлы: вес = 1

**shouldProcessLine()**
- Реализует взвешенное распределение строк CSV
- Вычисляет позицию в цикле весов: `line_number % total_weight`
- Определяет, какой процесс должен обработать данную строку
- Обеспечивает пропорциональное распределение согласно весам

#### Обновленные функции

**readCSV()**
- Принимает параметры весов: `rank_weights` и `total_weight`
- Использует `shouldProcessLine()` вместо простого round-robin
- Распределяет данные пропорционально мощности узлов

**main()**
- Определяет тип узла при запуске
- Собирает веса всех процессов через `MPI_Allgather`
- Вычисляет общий вес кластера
- Выводит информацию о распределении узлов
- Показывает количество обработанных строк каждым процессом

## 🔧 Технические детали

### Алгоритм взвешенного распределения

```
Для строки N:
1. Вычислить позицию в цикле: pos = N % total_weight
2. Инициализировать cumulative_weight = 0
3. Для каждого процесса P:
   a. cumulative_weight += weight[P]
   b. Если pos < cumulative_weight:
      - Строка N назначается процессу P
      - Выход из цикла
```

### Пример цикла (total_weight = 16)

```
Позиция 0-2:   Процесс 0 (GPU, вес 3)
Позиция 3-5:   Процесс 1 (GPU, вес 3)
Позиция 6-8:   Процесс 2 (GPU, вес 3)
Позиция 9-11:  Процесс 3 (GPU, вес 3)
Позиция 12:    Процесс 4 (CPU, вес 1)
Позиция 13:    Процесс 5 (CPU, вес 1)
Позиция 14:    Процесс 6 (CPU, вес 1)
Позиция 15:    Процесс 7 (CPU, вес 1)
```

Цикл повторяется каждые 16 строк.

## 📈 Производительность

### Теоретическое ускорение

При равной скорости обработки строки:
- Без взвешенного распределения: Tmax = T_total / 8
- С взвешенным распределением: Tmax ≈ T_total / (4×3 + 4×1) × 3 = 3T_total / 16

**Улучшение**: Если GPU узлы действительно в 3 раза мощнее, все узлы завершат работу одновременно, минимизируя время простоя.

### Практические результаты

Реальное ускорение зависит от:
- Фактической производительности GPU vs CPU
- Скорости чтения файла
- Сложности обработки данных
- Накладных расходов MPI

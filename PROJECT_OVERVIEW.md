# ОБЗОР ПРОЕКТА: Анализ Steam Games с OpenMPI

## 📋 Краткое описание

Этот проект содержит полную реализацию параллельного анализа большого CSV файла с данными об играх Steam. Программа использует OpenMPI для распределения вычислений на кластере из 4 узлов с **интеллектуальным распределением нагрузки**: GPU узлы получают в 3 раза больше данных, чем CPU узлы, для оптимального использования вычислительных ресурсов.

## 🎯 Решаемая задача

### Исходные данные
- Большой CSV файл `games.csv` с данными об играх из Steam
- Источник: https://www.kaggle.com/datasets/fronkongames/steam-games-dataset
- Формат: AppID, Name, Price, DLC count, Windows, Mac, Linux, Positive, Negative, Publishers, etc.

### Требования к анализу

1. **Группировка по платформам**: Windows, Mac, Linux (группы могут пересекаться)
2. **Группировка по цене**: Интервалы по $5 ($0-5, $5-10, $10-15, ...)
3. **Поиск топ-издателей**: В каждой группе найти 5 издателей с наибольшим отношением DLC/игры
4. **Статистика**: Для каждого издателя вывести:
   - Количество опубликованных игр
   - Мат. ожидание отношения положительных отзывов к отрицательным

### Технические требования

- ✅ Использование OpenMPI для параллелизации
- ✅ Работа на 4 узлах (2 CPU: altocpu1, altocpu2 + 2 GPU: altogpu1, altogpu2)
- ✅ Интеллектуальное распределение нагрузки с учетом типа узла (GPU/CPU)
- ✅ Конфигурация через SLURM
- ✅ 2 задачи на узел (всего 8 параллельных процессов)
- ✅ Взвешенное распределение: GPU узлы - вес 3, CPU узлы - вес 1

## 🏗️ Архитектура решения

### Параллелизм

```
┌─────────────────────────────────────────────────┐
│              games.csv (исходные данные)         │
└─────────────────────────────────────────────────┘
                        │
            ┌───────────┴───────────┐
            │  Weighted distribution │
            │  GPU: 75%, CPU: 25%    │
            └───────────┬───────────┘
                        │
        ┌───────────────┼──────────────────┐
        │               │                  │
   ┌────▼────┐     ┌───▼────┐       ┌────▼────┐
   │ GPU 1   │     │ GPU 2  │  ...  │ CPU 2   │
   │ (18.7%) │     │(18.8%) │       │ (6.3%)  │
   └────┬────┘     └───┬────┘       └────┬────┘
        │               │                  │
        └───────────────┼──────────────────┘
                        │
                  ┌─────▼─────┐
                  │ Rank 0    │
                  │ Aggregates│
                  └─────┬─────┘
                        │
            ┌───────────▼───────────┐
            │ analysis_results.txt  │
            └───────────────────────┘
```

### Алгоритм обработки

```
1. MPI_Init()
   └─> Инициализация 8 процессов на 4 узлах

2. Распределенное чтение
   ├─> Процессы определяют тип узла (GPU или CPU)
   ├─> Собирается информация о весах всех процессов
   ├─> GPU процессы (вес=3) читают больше строк
   ├─> CPU процессы (вес=1) читают меньше строк
   ├─> Процесс 0-3 (GPU) читают ~18.75% каждый
   └─> Процесс 4-7 (CPU) читают ~6.25% каждый

3. Для каждой платформы (Windows, Mac, Linux):
   ├─> Фильтрация игр по платформе
   ├─> Группировка по ценовым интервалам
   ├─> Агрегация статистики по издателям
   │   ├─> Подсчет игр
   │   ├─> Подсчет DLC
   │   └─> Расчет отношения отзывов
   ├─> Сортировка по DLC/игра
   ├─> Выбор топ-5
   └─> Вывод результатов (только rank 0)

4. MPI_Finalize()
   └─> Завершение работы
```

## 📊 Производительность

- **Ускорение**: Оптимизировано для гетерогенного кластера
- **Масштабируемость**: Адаптивная с учетом мощности узлов
